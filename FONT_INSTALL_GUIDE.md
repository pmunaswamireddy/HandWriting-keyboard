# Handwriting Keyboard — Font Install Guide

## How Your Handwriting Appears Everywhere (WhatsApp, Telegram, etc.)

The app generates a real **TrueType Font (.ttf)** from your handwriting glyphs.
Once installed, every app that uses your system font will render text in your handwriting.

---

## Android Installation (Without Root)

### Using iFont or zFont 3 (Recommended)

1. **Open Handwriting Keyboard app**
2. Go to **Settings → Generate Font** → tap **Generate**
3. Once generated, tap **Install Font**
4. The app will open **iFont** or **zFont 3** with your font pre-loaded
5. In iFont/zFont, tap **Apply** → **Set as system font**
6. Phone restarts font (some ROMs may require reboot)
7. Open WhatsApp → Type a message → **Your handwriting appears!** ✅

### Supported Android Launchers
- Samsung One UI: ✅ Full support via Good Lock / Fonts app
- MIUI (Xiaomi): ✅ via Themes → Font
- ColorOS (OPPO): ✅ via Personalisation → Font
- Stock Android 12+: ✅ via iFont/zFont3

---

## Windows Installation

1. **Open Handwriting Keyboard app**
2. Go to **Settings → Generate Font** → tap **Generate**
3. Tap **Install on Windows**
4. A one-time **UAC prompt** (Admin permission) will appear — click **Yes**
5. Font is registered system-wide via `AddFontResource()` Win32 API
6. Open Notepad / Word / Browser → **Your handwriting appears!** ✅

---

## Share as Image (No Font Install Needed)

If you prefer not to install a system font, use the **Share as Image** button:

1. Type your message in any app
2. On the keyboard toolbar, tap the **Image Share** button (🖼️)
3. Your typed text renders as a beautiful handwriting image
4. Share the image to WhatsApp, Instagram, etc.
5. Recipients see your handwriting — no font install needed on their end ✅

## WhatsApp Sticker Pack

Export frequently used words/phrases as a WhatsApp sticker pack:
1. Go to **Settings → Export Stickers**
2. Type words you want as stickers
3. Export → WhatsApp opens and adds them to your sticker collection
4. Send stickers that look exactly like your handwriting ✅
